# Ship bow holder

A 3D-printable stand for supporting a ship model at the bow. The holder has a
35 mm long base and a slot for an approximately 8 mm thick bow board. The
8.5 mm slot includes 0.5 mm of clearance.

## Physical test

The holder was successfully printed and fitted to the ship's bow. It fulfilled
its intended support function. The side profile was refined using printed fit
gauges and confirmed against the bow.

Further work is planned to improve the holder's appearance. This version
preserves the working design before those visual changes.

## Source

Open [ship-bow-holder.scad](ship-bow-holder.scad) in OpenSCAD. The `part`
selector displays the holder, the thin profile gauge, or both. Dimensions are
in millimetres.
