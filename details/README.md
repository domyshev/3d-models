# Component library and design evolution

This directory collects independently viewable components, meaningful design
variants, and experiments by Ilia Domyshev. Components may be useful in projects
beyond the model that originally motivated them. Git records the transformation
history; distinct SCAD entry points preserve useful structural alternatives.

The projects in [models](../models/) do not require this directory. Their source
and release dependencies remain self-contained. Component changes do not update
released models automatically.

## Components

- [MagSafe clamp ring](magsafe-ring/README.md): plain cylindrical recesses and a
  later variant with separate toothed inserts seated on both outer arm faces.
  A new outside-only textured variant adds R1 external rim roundovers.
- [Textured M12 clamp fasteners](m12-clamp-fasteners/README.md): the existing
  bolt/nut sizes with textured external faces and exposed ends, preserving
  smooth bearing faces and the original threads.
- [Vertical support](vertical-support/README.md): direct-base support with four
  threaded studs, in original-height, 10 mm shorter, and decoratively textured
  shorter variants.
  A further rounded/hollow variant adds a floor-matched base, raised fork
  bridge, and all-over external texture while preserving the tested variant.
- [Sculpted one-piece legs](sculpted-leg/README.md): long and short textured
  legs widening from a 17 mm threaded root to an integrated 28 mm cylindrical
  foot with an 8 mm bearing band and domed end. Their textured ends are identical;
  only the smooth root length differs.

## Development conventions

Each component README records its originating model, construction stages,
reasons for changes, dependencies, and physical-test status. Experiments are not
release-ready print profiles. Successful OpenSCAD rendering is not a substitute
for slicing checks, fit checks, or a physical print. No Bambu or STL artifacts
are generated by adding these sources.

These initial snapshots were extracted on 2026-10-01 from the current development
sources, not from an immutable release tag. Future changes should remain local
to this library until explicitly integrated into a model.
